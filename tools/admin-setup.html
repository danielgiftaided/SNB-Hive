Add these three settings in Supabase

Open your SNB Hive project → Edge Functions → Secrets. Add each setting below using its exact name and copied value. Keep your existing ADMIN_EMAIL, email and payment settings.

Save all three settings, then sign in with your existing admin email and the password you entered above. A frontend release is not needed to use these settings with the already deployed sign-in function.
